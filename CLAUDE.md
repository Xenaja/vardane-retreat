# Женский ретрит по Кундалини йоге — Вардане (лендинг)

## Продукт и аудитория
Женский ретрит «Йога и процветание», **9—12 октября 2026** (4 дня / 3 ночи),
ретрит-центр «Энергия солнца», пос. Вардане, Лазаревский район Сочи.
Ведёт **Татьяна Иванская**, духовное имя **Атма Бани Каур** — преподаватель
Кундалини йоги, школа Амрит Нам Саровар (Франция). Приглашённый мастер —
Павитра (Три йога, пранаяма, гонг-медитация), тот же, что у соседнего ретрита.
Аудитория: женщины, которые устали, не выключаются и давно не были наедине с собой.

Цена **40 000 ₽ со всем включённым**, предоплата 7 000 ₽ бронирует номер.

⚠️ **Это отдельный лендинг, не правка соседнего.** `../Zakharevith/` (moresily.ru,
бизнес-тренинг Захаревича, те же даты и площадка) — только источник фото площадки,
приёмов вёрстки и воркера формы. Его файлы не трогаем.

Одно действие на всю страницу: **«Забронировать место»** → форма → Cloudflare Worker
`sochi-retreat-lead-form.xenonline77.workers.dev` → Telegram. Префикс в поле `task`: `[тати]`.

иначе браузер получит CORS-ошибку — curl её не покажет.

## Структура (15 блоков)
Шапка (sticky) → герой `#top` → для кого `#who` (01) → ведущая `#author` (02)
→ перебивка «берег» → программа `#program` (03) → ритм дня `#day`
→ с чем вы уезжаете `#results` → Павитра `#guest` (тёмная) → перебивка «гонг»
→ место `#venue` (04) → школа `#proof` → стоимость `#price` (05) → вопросы `#faq`
→ заявка `#form` (06, тёмная) → футер.

Четыре точки действия: кнопка шапки · герой · «С чем вы уезжаете» · плашка цены,
плюс липкая полоса снизу на телефоне и сама форма.

## Стиль — по хэндофу `design_handoff_vardane_retreat/README.md`
Дизайн утверждён и **заморожен**: правки только по технической необходимости
и с записью в `DECISIONS.md`.
```
ivory #FDF6EF · peach #FAEBE2 · card #FFFFFF
raspberry #A62F55 (заголовки) · coral #C4685E (акценты, время, маркеры)
emerald #154744 (тёмные секции, кнопки) · apricot #F0C3A9 (акцент на тёмном)
```
- ⚠️ `coral` на белом даёт 3.83:1 — годится только для крупного и маркеров,
  наборный текст им не красить. Полная таблица замеров — в шапке `css/tokens.css`.
- ⚠️ Отклонение: прозрачность кремового для строки 14px поднята с .6 до .68
  (на .6 выходило 4.28:1, ниже нормы).
- Шрифты: **Cormorant Garamond** (заголовки uppercase, цифры, цитаты, курсив)
  и **Golos Text** (текст и интерфейс). H1/H2 — прописными с трекингом .02–.035em.
- ⚠️ Cormorant рисует ноль узким: на кегле 22px «01» читается как «()1».
  Поэтому в `body` стоит `lining-nums`, а номера шагов идут без ведущего нуля.
- Формы: карточки радиус 26px с тенями, арки на фото (`260px 260px 28px 28px`),
  дуги на стыке секций (`--arc`, 80px + `margin-top:-40px`), кнопки-pill.
- Иконки — инлайновые SVG 24–26px, `stroke-width:1.2`, `currentColor`. Внешних
  иконочных наборов нет.
- Декоративные «дышащие» окружности `.orb` — только на `position:relative`
  контейнерах с `overflow:hidden`, иначе растягивают страницу вбок.
